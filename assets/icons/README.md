# Interface Icons

Icons for the desktop interface must be first-party, visually consistent, and bundled locally.

Planned groups:

- Navigation: cashier, products, transaction history, reports, settings.
- Actions: search, add, edit, deactivate, remove, save, cancel.
- Transaction: cart, cash, receipt, payment success, warning.
- System: backup, restore, folder, information, error.

Prefer monochrome icons with a consistent stroke and simple geometry. Provide PNG/GIF exports for runtime use if the selected Tkinter implementation cannot display the vector source directly. Avoid external icon fonts and remote icon libraries.
