# Brand Assets

The approved logo is being created separately and has not been supplied to this repository yet.

When it is ready, keep the original master and export only the sizes the application actually needs, for example:

- `kasirkita-logo.png` — header and about screen.
- `kasirkita-logo.svg` — scalable master, if supplied in SVG.
- `kasirkita-app.ico` — Windows application/window icon.
- `kasirkita-mark.png` — compact mark for small surfaces, only if the logo design includes one.

Do not create a fake final logo or stretch one small export to every size. Keep transparent backgrounds where appropriate and verify the result at both small and large sizes.
